Overview

Silent Scraper Academy is a full-stack cybersecurity training platform designed around an intentional vulnerable web application lab. It gives users a safe, realistic environment to practice discovering, exploiting, and remediating genuine web application flaws.

Objective

Design and implement controlled vulnerabilities reflecting the OWASP Top 10, then perform exhaustive black-box and white-box penetration testing to document attack paths and write comprehensive remediation reports.

Attack Surface & Technical Implementation

  • SQL Injection (SQLi): Unsanitized input parameters in authentication and product queries.
  • Cross-Site Scripting (Stored & Reflected XSS): Improperly escaped user comments and URL parameters.
  • Broken Access Control (IDOR): Predictable object references exposing user profiles and administrative endpoints.
  • Session Handling: Flawed token invalidation and cookie security flags.

Tools & Findings

Burp Suite was leveraged for manual request tampering and payload crafting. FFUF was used for directory and parameter discovery. All vulnerabilities were cataloged with CVSS scores, proof-of-concept exploits, and code-level remediation snippets.

Overview

HAXMED CryptoLab is a professional desktop engineering toolkit designed from the ground up to provide a visual, safe, and entirely offline environment for exploring, verifying, and testing cryptographic algorithms, hashing functions, and forensic data payloads.

Core Architectural Modules

  • Classical & Historical Ciphers: Caesar, Vigenère, Playfair, Affine, and Rail Fence with frequency analysis heuristics.
  • Modern Symmetric & Asymmetric Encryption: AES (CBC, GCM, CTR modes), DES/3DES, RSA keypair generation, signature verification, and hybrid key exchange simulation.
  • Hashing Forensics & Checksums: Multi-algorithm integrity hashing (MD5, SHA-1, SHA-256, SHA-512, BLAKE2), HMAC verification, and file entropy scanning.
  • Heuristic Auto-Detection Engine: Automatically detects format encodings (Base64, Hex, Binary) and predicts candidate cipher types based on statistical text distribution.
  • Local-Only Process Architecture: Zero network transmission; sensitive inputs and keys are held solely in volatile memory to protect user data.

Engineering & Standards

Built with decoupled PySide6 / Qt 6 UI architecture, strict PEP 8 compliance, comprehensive unit test suites using pytest, and standalone binary packaging scripts for Windows and Linux.
